# 个股智能分析 (dsh-stock-analyzer)

DSH Web 插件：输入股票名称或代码（如 `600519`、`贵州茅台`、`sh600519`），一次性给出这只 A 股的**行情估值、技术指标、资金流、行业板块、基本面、资讯、市场热点**与**规则化投资建议**，并把同一份分析通过 `stock_analysis` 工具提供给 Agent。

数据源：**同花顺公开接口**（行情/四档资金流/K线/F10/行业/热榜/资讯）+ **东方财富公开接口**（资金流历史、主要财务指标、公告与资讯，用于补充与互验）。

## 页面

侧边栏「个股分析」图标 → 打开分析面板：

1. 搜索框（代码或名称，回车即可）+ 示例标的；
2. 概览：现价、涨跌幅、成交额、换手、量比、振幅、PE/PB、市值、52 周区间；
3. 技术面：MA5/10/20/60/120/250、MACD、KDJ、RSI、BOLL、ATR、BIAS、量能、支撑/压力/止损 + 趋势评分；
4. 资金面：特大单/大单/中单/小单四档净额、主力净额与占比、外盘/内盘；
5. 行业与板块：所属申万行业、同花顺行业板块涨跌与排名、板块净流入、领涨股、同行个股、热门板块前 5；
6. 基本面：报告期、EPS、净利润与同比、毛利率、净利率、ROE、资产负债率、营收增速，附同花顺财务诊断与行业排名；
7. 消息面：公司公告（F10）+ 同花顺财经相关资讯；
8. 热点：同花顺热榜名次、热度、上涨原因、概念题材与概念贴合度；
9. 投资建议：综合评分（技术 35% / 资金 20% / 估值 15% / 财务 15% / 行业 10% / 情绪 5%）、评级、操作建议、周期、置信度、建议仓位、利好、风险、关键价位、免责声明。

## Agent 工具

`stock_analysis`：

| 参数 | 说明 |
| --- | --- |
| `code` | 股票代码，如 `600519`、`sh600519`、`600519.SH`（与 `name` 二选一） |
| `name` | 股票名称，如 `贵州茅台`（与 `code` 二选一） |
| `section` | `all`（默认）/ `summary` / `technical` / `funds` / `industry` / `finance` / `news` / `hot` / `advice` |
| `refresh` | 是否绕过 5 分钟缓存强制刷新 |

## HTTP 接口

- `GET /dsh-stock/analyze.json?q=600519[&refresh=1]`：完整分析 JSON（形状见 `CONTRACT.md`）
- `GET /dsh-stock/search.json?q=茅台`：代码/名称检索

## 配置

在 `cordis.patch.yml` 的入口 `config` 覆盖：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `cacheMinutes` | `5` | 单只股票分析结果缓存分钟数（1-60） |
| `f10CacheHours` | `6` | 同花顺 F10 页面缓存小时数（1-72） |
| `eastmoneyEnabled` | `true` | 是否启用东方财富第二数据源（关闭后仅用同花顺） |
| `requestTimeoutMs` | `25000` | 单次上游请求超时（5000-60000） |

## 数据口径

- **行情/资金流**：同花顺 `d.10jqka.com.cn/v6/realhead`，四档字段 223/224（特大单买卖）、225/226（大单）、237/238（中单）、259/260（小单），单位元；主力 = 特大单 + 大单；净流入 = 四档合计。字段缺失时用「(外盘 − 内盘) × 成交均价」估算并标记 `estimated`。
- **K 线**：同花顺 `v6/line/.../01/all.js`（约 6000 个交易日），指标全部在本地计算（MACD 柱 = 2×(DIF−DEA)，KDJ(9,3,3)，RSI Wilder，BOLL(20,2)，ATR(14)，BIAS(6/12/24)）。
- **F10**：`basic.10jqka.com.cn`（GBK 页面），解析公司亮点/主营业务/申万行业/估值/EPS/总股本/质押/股东集中度、财务诊断（毛利率、净利率、ROE、资产负债率、营收与净利增速、现金流）、概念题材、公司公告。
- **行业**：`q.10jqka.com.cn/thshy/` 行业板块排行。页面默认只按涨跌幅展示前 50 个板块，插件同时抓取降序与升序两页并合并，覆盖同花顺全部约 90 个行业板块（涨跌幅/成交额/净流入/涨跌家数/领涨股），按申万行业名归一化匹配到同花顺行业板块（如 白酒Ⅱ → 白酒、电池Ⅱ → 电池），再取板块成分股定位个股在行业内的涨跌幅排名。
- **热点**：`dq.10jqka.com.cn` 同花顺热榜（热度、上涨原因、人气标签）。
- **资讯**：`news.10jqka.com.cn` 财经资讯流 + F10 公司公告；资讯按股票名/行业名做关键词匹配，不足时补市场要闻。
- **东方财富**：`push2his` 资金流历史（近 30 个交易日主力/超大单/大单/中单/小单净额，派生 5/10/20 日主力净流入）、`emweb` F10 主要财务指标（EPS/BPS/营收/净利/毛利率/净利率/ROE/资产负债率，同花顺缺失时补位）、`np-anotice-stock` 公告、`search-api-web` 资讯搜索。任一接口失败时优雅降级，并在数据源徽标中显示原因。
- **名称检索**：同花顺未提供公开 suggest 接口，代码/名称检索使用新浪 `suggest3.sinajs.cn`（仅用于名称 → 代码；行情、指标、行业、新闻、热点全部来自同花顺/东方财富）。
- **财务诊断**：较新的同花顺财务页（如 000001）不再输出服务端「财务诊断」文本块，此时毛利率/净利率/现金流比率为 `null`，但 ROE 与资产负债率仍通过杜邦分析兜底；页面以「—」显示缺失项而不会报错。

## 投资建议模型

规则化、可解释、非 LLM 生成：六个维度打分加权得到 0-100 综合分，映射为「强烈看多 / 看多 / 中性 / 谨慎 / 看空」，再根据技术位给出操作、周期、仓位、支撑/压力/止损/目标与买卖区间，并汇总利好与风险条目。所有结论在页面与工具中都附带免责声明。

## 限制

- 同花顺公开接口有频率限制；行情缓存 5 分钟、K 线 30 分钟、F10 页面 6 小时、行业与热榜 10-30 分钟，失败时返回缓存/降级数据并在 `warnings` 中说明。
- 同花顺热榜仅覆盖约 100 只热门股，未上榜股票的「热榜名次」为空。
- F10 页面为 HTML 解析，页面改版可能导致个别字段缺失（返回 `null` 而不是报错）。
- 北交所部分标的缺少四档资金流字段，使用估算值并标注。
- 本插件不构成投资建议，股市有风险，投资需谨慎。

## 安装与验证

```powershell
# 在 DSH 中安装（工作区目录即插件包根目录）
plugin_manager install_bundle  target: <项目路径>\stock-analyzer
```

- 安装后 Host 立即激活：`stock_analysis` 工具、`/dsh-stock/analyze.json`、`/dsh-stock/search.json` 可用；Web 页面侧边栏出现「个股分析」图标，`main` 面板 key 为 `stock-analyzer`。
- 修改 `index.js` 后（本插件以目录软链方式安装），在插件管理里关闭再启用该插件即可加载新的 Host 模块，无需重启 DSH。
- 自测脚本：
  - `node stock-analyzer/test/parse-check.mjs`：页面解析 110 条断言（600519 / 000001 双样本）
  - `node stock-analyzer/test/smoke.mjs 600519`：不安装插件、用假 Host 上下文跑通「抓取 → 指标 → 建议」全链路
